# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：素のLLMは質問に直接回答するのに対し、エージェントは `search_glossary` で用語集を確認してから回答する。エージェントは用語集の「宿題の3レベル」の説明を根拠にできる。
- `--trace` で見えたツール呼び出し（ツール名と引数）：質問「LoRAとQLoRAの違いは？」に対し、`search_glossary({'query': 'LoRA'})` と `search_glossary({'query': 'QLoRA'})` が呼ばれた。
- 1つの質問での LLM 呼び出し回数（`requests`）：2回。ツール呼び出しも2回だった。
- 追加したツールと、docstring に書いた説明：`make_quiz(lecture)` を追加してエージェントに登録した。指定回の用語から1つ選んで意味を問う問題を作り、用語集の定義を答えとして返す。指定回の用語の理解を確認したいときに使う。

## 宿題

- 取り組んだレベル：基礎
- やったこと：`search_glossary` の docstring を変更し、検索語を1つに限定せず、複数の用語をまとめて指定してよいとした。
- 結果：「LoRAとQLoRAの違いは？」を変更前後で実行した。変更前は `search_glossary` が `LoRA` と `QLoRA` を別々に検索し、`tool_calls=2` だった。変更後は `query='LoRA QLoRA'` の1回で検索し、`tool_calls=1` になった。どちらも `requests=2` で、回答はいずれも両用語の違いを説明した。
- 気づき・疑問：ツールのdocstringを変えると、モデルが作る引数やツール呼び出し回数が変わることが分かった。`requests` はモデルへの通信回数で、ツール呼び出し回数とは別だった。
